# QSPICE DC/DC Converter

Prototipo Boost 48–96 V con control digital C++ en QSPICE.

V5: planta conmutada, PI en cascada, máquina de estados, ADC/PWM discretizados y ensayos separados. La simulación conjunta V5 en QSPICE está pendiente de validación. No es un diseño para hardware real.

Ver `LEEME.txt` para instrucciones de ejecución una vez importados los archivos.
